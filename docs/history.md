# 履歴

## 2026-08-12 — ローカルHTMLを受けられるようにした

既定ブラウザにすると `.html` ファイルの担当も Ferry になる。file: を捨てていたため、
`md`（markdown プレビュー）で開いた HTML が**無言で開かなくなっていた**。
ログには「扱えないスキーム file://...」だけが残る。

file: を受けて、設定ブラウザへそのまま渡すようにした。ローカルファイルにはホストが無く
ルールも前処理も当てられないため、パネルは出さない（修飾キーを押していれば出す）。
選択パネルの「記憶」も、ホストが無いときは押しても何も起きないので隠す。

## 2026-08-12 — 設定の行のレイアウトを揃える

ラベルを左揃えにして縦に並べ、コントロールの左端と幅を揃えた（本人のモックに合わせた）。
あわせて「逃げ先」を「設定ブラウザ」に改名。

SwiftUI の `Picker` は**いちばん広いメニュー項目の幅**でボタンの幅が決まるため、
`.frame(width:)` を与えてもボタンは伸びず、その枠の中央に置かれるだけになる。
- ラベルは `labelsHidden()` にして自分で `Text` を置き、幅を固定する
  （`Picker("修飾キー", ...)` のままだとラベルが右揃えになる）
- ボタンの左端を揃える: `.frame(maxWidth: .infinity, alignment: .leading)` を内側に重ねる
- **ボタンの幅を揃える: 項目そのものに `.frame(width:)` を掛ける**。
  これをやらないと「option」の行と「Google Chrome Canary」を含む行で幅が変わる

## 2026-08-12 — 画面の文言を削る

「アプリ内に文字や文章が多すぎる」「設定項目に文章を用いない」という指摘を受けて、
画面から説明文をすべて外し、項目名を名詞だけにした。意味は docs/usage.md に移した。

| 前 | 後 |
|---|---|
| ルールを飛ばしてパネルを出す修飾キー | 修飾キー |
| 逃げ先のブラウザ | 逃げ先 |
| 選択パネルに出すブラウザ（見出し） | パネル |
| Ferry を既定のブラウザにする | Ferry にする |
| Safari に戻す | 戻す |
| 一時停止（すべて Safari で開く） | 一時停止 |
| ログイン時に起動 | 自動起動 |
| 以後 example.com はこのブラウザで開く | 記憶 |
| トラッキングパラメータを消す | トラッキング |
| 短縮URLを展開してから開く | 短縮URL |

あわせて、パネル下部の操作キー一覧、各設定の下にあった但し書き、
「既定ブラウザを Ferry にしました」のような経過表示、ログイン項目の失敗時の長い案内文を削除した。
メニューの「既定ブラウザになっている / ではない」は、名詞1つ＋チェックマークに変えた。

## 2026-08-12 — 初版

リンクを開くブラウザを選べる既定ブラウザアプリとして新規作成した。

作ったもの:

- URL受信 → 前処理 → 修飾キー判定 → ルール照合 → 選択パネル、の一周
- ルール3種（ホスト後方一致 / ワイルドカード / 正規表現）と設定画面
- 選択パネルからの1操作ルール追加
- 短縮URL展開とトラッキングパラメータ除去
- 既定ブラウザの登録と、元のブラウザへの復元
- メニューバー（一時停止、履歴からの開き直し、ログイン時に起動）

作りながら変えた判断:

- **`MenuBarExtra` をやめて `NSStatusItem` にした。**
  実行時に `.accessory` へ切り替える構成だとパネルが開かず、画面外に空ウィンドウが残った。
  当初の設計では `MenuBarExtra` を使うつもりだった
- **選択パネルを `.titled` から `.borderless` にした。**
  タイトルバーの分だけ上に余白が残ったため
- **設定ファイルの監視をディレクトリだけからファイル＋ディレクトリの両方にした。**
  ディレクトリだけだと、その場で上書きされたときに更新日時が変わらず発火しなかった

確認したこと（`~/Library/Logs/Ferry.log` と画面で）:

- 未起動から URL を受け取れる。`application(_:open:)` は
  `applicationDidFinishLaunching` より先に呼ばれる
- `utm_source` / `fbclid` が消え、`id` は残る
- 302 を辿って展開し、そのあとで utm を落とす（展開→除去の順序）
- `github.com` のルールが `gist.github.com` にも当たる
- 修飾キーを押しながらだとルールを飛ばしてパネルが出る
- 一時停止中はルールを無視して逃げ先へ流れる
- LaunchServices に `claimed schemes: ferry:, http:, https:` として登録されている

## 今後

- **送信元アプリごとの分岐**（Discord からは Chrome、メールからは Safari）。
  送信元の特定は `NSAppleEventManager.shared().currentAppleEvent` の `keySenderPIDAttr` から
  PID を取るのが本筋。取れないときは `NSWorkspace.didActivateApplicationNotification` を
  監視して「直前に手前にいた自分以外のアプリ」を覚えておく方式で補う
- Chrome のプロファイル指定（`--profile-directory`。新規起動時しか引数が効かない制約あり）
- 特定URLをブラウザではなくアプリで開く（x.com → X.app など）
- 配布するなら Developer ID 署名と公証
