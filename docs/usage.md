# 使い方

最終更新: 2026-08-12

**アプリの画面には説明を出していない。** 項目の意味はすべてここに書く。

## 最初にやること

1. `./build.sh install` で `~/Applications/Ferry.app` に入れて起動する
2. メニューバーの船アイコン → **設定…**
3. 「既定」の **Ferry にする** を押す（システムの確認ダイアログが出る）
4. 「パネル」で、選択パネルに並べたいブラウザだけを残す

押す前の既定ブラウザは自動で控えられる。同じ場所に **戻す** が出るので、いつでも戻せる。
ボタンが効かないときは システム設定 → デスクトップとDock → デフォルトのWebブラウザ から選ぶ。

## 選択パネル

ルールに当たらなかった URL は、マウスカーソルのそばにパネルが出る。

| 操作 | 動き |
|---|---|
| `1` 〜 `9` | その番号のブラウザで開く |
| `←` `→` / `tab` | 選択を動かす |
| `return` | 選択中のブラウザで開く |
| `space` | 「記憶」を切り替える |
| `esc` | 中止する（元いたアプリに戻る） |
| パネルの外をクリック | 中止する |

**記憶** … チェックしたまま選ぶと、そのホストを以後そのブラウザで開くルールが1本増える。
普段のルール作成はこれで足りる。`www.` は落として登録するので、裸のドメインにも当たる。

## ルール

上から順に照合し、最初に当たったものを使う。順番は `∧` `∨` で入れ替える。

| 種類 | 書き方 | 当たるもの |
|---|---|---|
| ホスト | `github.com` | `github.com`、`gist.github.com`（サブドメインを含む後方一致） |
| パターン | `*.tmu.ac.jp/*` | スキームを除いた `host/path?query` に対するワイルドカード（`*` のみ） |
| 正規表現 | `\.pdf$` | URL 全体に対する部分一致 |

左のチェックを外すと、消さずに無効にできる。

## 設定画面の項目

| 場所 | 項目 | 意味 |
|---|---|---|
| 既定 | **更新** | いまの既定ブラウザを取り直して表示する |
| 既定 | **戻す** | Ferry にする前の既定ブラウザへ戻す |
| 既定 | **Ferry にする** | Ferry を既定のブラウザにする |
| 動作 | **修飾キー** | 押しながらクリックするとルールを無視して必ずパネルを出す（既定は option）|
| 動作 | **設定ブラウザ** | 一時停止中と、ルールの指すブラウザが見つからないときに開くブラウザ。「自動」なら先頭のもの |
| パネル | チェック | 選択パネルに並べるブラウザ。全部外すと全ブラウザが出る |
| パネル | **更新** | インストール済みブラウザを探し直す |
| URL | **トラッキング** | 下の欄に書いたクエリパラメータを開く前に消す。1行に1つ、末尾 `*` はワイルドカード |
| URL | **短縮URL** | 下の欄に書いたホストだけ、開く前に本当の行き先へ展開する。1行に1ホスト |
| ファイル | **設定** / **ログ** | `config.json` と `Ferry.log` を Finder で表示する |

**修飾キーはリンクが開き終わるまで押したままにする。**
短縮URLの展開で最大3秒待つことがあり、途中で離すと取りこぼす。

**短縮URLの展開は明示したホストだけが対象。** 全ホストを対象にしないのは、遅くなるのと、
開く前に相手のサーバへ接触してしまうため。展開は最大3秒で打ち切り、失敗したら元の URL で開く。

**トラッキング除去は書いたものだけを消す。** 知らないパラメータを消す方式にはしていない
（正常な URL を壊すため）。

## ローカルのHTMLファイル

Ferry を既定ブラウザにすると、**`.html` ファイルの担当も Ferry になる**。
ローカルファイルにはホストが無くルールを当てられないので、
**「設定ブラウザ」でそのまま開く**（修飾キーを押していればパネルを出す）。
`md`（markdown プレビュー）のようにローカルHTMLを `open` するコマンドはこの経路を通る。

## メニューバー

| 項目 | 意味 |
|---|---|
| **既定ブラウザ** | チェックが付いていれば Ferry が既定になっている（表示のみ）|
| **一時停止** | ルールもパネルも通さず、すべて「設定ブラウザ」へ流す |
| **履歴** | 直近5件。選ぶとパネルを出して別のブラウザで開き直す |
| **自動起動** | ログイン時に起動する |

「自動起動」で **登録できませんでした** と出たら、ad-hoc 署名が原因。
システム設定 → 一般 → ログイン項目 から手で追加する。

## うまく動かないとき

まずログを見る。受信から起動までの経路が全部残っている。

```bash
tail -f ~/Library/Logs/Ferry.log
```

リンクが開けなくなったら、メニューバーの **一時停止** を入れる。
Ferry を既定から外すときは、設定画面の **戻す**。

設定ファイル（`~/Library/Application Support/one.yoshito.Ferry/config.json`）は
手で編集してよい。保存すると Ferry が読み直す。
