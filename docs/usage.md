# 使い方

最終更新: 2026-08-12

## 最初にやること

1. `./build.sh install` で `~/Applications/Ferry.app` に入れて起動する
2. メニューバーの船アイコン → **設定…**
3. 「**Ferry を既定のブラウザにする**」を押す（システムの確認ダイアログが出る）
4. 「選択パネルに出すブラウザ」で、パネルに並べたいものだけを残す

既定ブラウザにする前に、そのときの既定ブラウザが控えられる。
設定画面に「**◯◯ に戻す**」ボタンが出るので、いつでも戻せる。

ボタンが効かないときは システム設定 → デスクトップとDock → デフォルトのWebブラウザ から選ぶ。

## 選択パネル

ルールに当たらなかった URL は、マウスカーソルのそばにパネルが出る。

| 操作 | 動き |
|---|---|
| `1` 〜 `9` | その番号のブラウザで開く |
| `←` `→` / `tab` | 選択を動かす |
| `return` | 選択中のブラウザで開く |
| `space` | 「以後このホストは…」のチェックを切り替える |
| `esc` | 中止する（元いたアプリに戻る） |
| パネルの外をクリック | 中止する |

## ルールの作り方

**普段は設定画面を開かなくてよい。** パネルで `space` を押してから番号を押すと、
「以後そのホストはこのブラウザで開く」ルールが1本追加される。
以後、同じホストのリンクはパネルを出さずに直接開く。

細かく決めたいときは設定画面の「ルール」で追加する。
上から順に照合し、最初に当たったものを使う。順番は `∧` `∨` で入れ替える。

| 種類 | 書き方 | 当たるもの |
|---|---|---|
| ホスト | `github.com` | `github.com`、`gist.github.com`（サブドメインを含む後方一致） |
| パターン | `*.tmu.ac.jp/*` | スキームを除いた `host/path?query` に対するワイルドカード |
| 正規表現 | `\.pdf$` | URL 全体に対する部分一致 |

## ルールを無視して選びたいとき

**option を押しながら**リンクをクリックすると、ルールを飛ばして必ずパネルが出る。
**リンクが開き終わるまで押したままにすること。**
短縮URLの展開で最大3秒待つことがあり、途中で離すと取りこぼす。

使うキーは設定画面で変えられる（既定は option）。

## URL の前処理

- **トラッキングパラメータを消す**: `utm_*` や `fbclid` など、設定に書いたものだけを消す。
  知らないパラメータは消さない（正常な URL を壊すため）
- **短縮URLを展開する**: `t.co` など設定に書いたホストだけ、開く前に本当の行き先へ展開する。
  最大3秒、失敗したら元の URL のまま開く。全ホストを対象にはしない
  （遅くなるのと、開く前に相手のサーバへ接触してしまうため）

## うまく動かないとき

まずログを見る。受信から起動までの経路が全部残っている。

```bash
tail -f ~/Library/Logs/Ferry.log
```

リンクが開けなくなったら、メニューバーから **一時停止** を入れる。
ルールもパネルも通さず、逃げ先のブラウザへ直接流すようになる。

Ferry を既定から外したいときは、設定画面の「◯◯ に戻す」を押す。
